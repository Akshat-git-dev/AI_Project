2. Feature Deep-Dive 1: Misconception Taxonomy & Live Sandbox (Item #5)

Dedicated Cognitive Science Interface (`MisconceptionTaxonomyView.tsx`)

Organizes student error patterns across 6 rigorous educational data mining archetypes with real-world questions and an instant diagnostic playground:

  • Conceptual Misunderstanding (38%): Mental model breakdown (e.g. attempting to mutate immutable Python tuples; applying Dijkstra to negative edge weights).
  • Wrong Formula Application (24%): Algebraic/symbolic inversion (e.g. sign flip in discriminant Δ = b² - 4ac; product rule derivative omission).
  • Careless Slip (18%): Execution oversight with intact conceptual understanding (e.g. root sign inversion; array 0-indexing fencepost errors).
  • Incomplete Logic (10%): Truncated reasoning chains (e.g. missing recursion base cases).
  • Terminology Confusion (6%): Lexical swaps across related concepts (e.g. Overriding vs Overloading).
  • Prerequisite Gap (4%): Missing foundational building blocks (e.g. matrix determinant singularity voids).
  • Live Sandbox Playground: Anyone can pick any question or type custom student response strings to test `MisconceptionClassifier.diagnose()` in real-time (~4ms latency).
